# Non-negotiable

A violation here is a financial or security bug, not a style issue.

## Money

Money is `int64` minor units plus an ISO currency code. Never a float — not in Go, not in
JavaScript, not in SQL. PHP 100.00 is `10000`. This is stated before any money exists
because the first wallet change must not be the one that decides it. The rule covers
every amount that is or feeds a balance; a statistic derived from amounts is an integer
in basis points, never a float, but it is not money and needs no arbitrary precision.

## Sessions

Opaque random tokens: 32 bytes from `crypto/rand`, delivered in an HttpOnly cookie,
stored only as a SHA-256 hash. Never a JWT, and never a token the browser can read.

Sessions are revoked, not deleted, so when a session ended stays on the record.

## Passwords

Argon2id with a per-hash random salt, compared in constant time. Never a bare hash, never
a fixed salt, never a comparison with `==`.

## Authority

The server is the only authority on identity, role, and account status. A role or a user
ID supplied by a client is input, never a fact. Request bodies reject unknown fields so a
client cannot try to set one.

## Indistinguishable failures

An unknown email and a wrong password return the same status, the same body, and cost the
same time to produce. Registration is the deliberate exception: it cannot both refuse a
duplicate and hide that the address is taken.

## CSRF

A state-changing request is refused unless its `Origin` header is on the allowlist. That
is the CSRF defence, and there is no token to store or replay: the browser sends `Origin`
on every write, and a cross-site page cannot forge it. A write with no `Origin` at all is
refused too, so a non-browser client must send one — `curl` gets
`-H 'Origin: http://localhost:5173'`.

The allowlist is `CORS_ALLOWED_ORIGINS`, exact origins only. A wildcard is illegal on
credentialed requests and makes the browser silently drop the session cookie.

## Storage

Nothing credential-shaped touches `localStorage` or `sessionStorage`.

## Identifiers and time

External identifiers are non-sequential UUIDs, generated by the database. Time is UTC
`TIMESTAMPTZ` in the database and RFC 3339 on the wire, converted only at the UI
boundary.

## Tests

Tests accompany every change touching money, auth, or permissions.

Database-backed tests read `TEST_DATABASE_URL`, falling back to `DATABASE_URL`, and skip
when PostgreSQL is unreachable. CI sets `REQUIRE_TEST_DATABASE=1` so a skip there is a
failure instead — a silent skip must never hide an auth bug.

Because of that fallback, `make test` must be safe to run against a developer's own
database. A test creates its rows under a marker it owns — the HTTP suite's accounts are
`@suite.test`, a package's fixtures carry a run-unique address — and removes only those
rows, reporting a cleanup that fails. Nothing truncates a table, and no assertion counts
a table it did not fill.

Auth tests drive a real `httptest` server with an `http.Client` that keeps cookies, so
cookie attributes, replay, and revocation are exercised the way a browser exercises them.
